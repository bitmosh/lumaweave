# gwells

Typed gravity-well physics engine for graphology graphs.

This is the source tree for the gwells module. For full documentation,
see the canonical doc (supersedes all individual gwells docs):

  `docs/canonical/GWELLS_PHYSICS.md`

(Previously: GWELLS_README.md, GRAVITY_WELL_SYSTEM_CONTRACT.md,
GWELLS_REGISTRY_PATTERNS.md, GWELLS_DIALECT_RADIAL_BACKBONE.md,
GWELLS_DIALECT_PARALLEL_SPINES.md, GWELLS_OVERVIEW.md,
GWELLS_CURRENT_STATE.md — all archived to prev99-archived/ at v100.0.4.)

The module is designed for future extraction as a standalone npm
package. Its only runtime dependency is `graphology`.
