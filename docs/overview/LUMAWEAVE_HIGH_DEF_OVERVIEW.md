# LumaWeave Project: High-Definition Overview

## 1. Project Overview

**LumaWeave** is a local-first, high-resolution, immersive platform
for visualizing and navigating complex code, data, and governance
structures. It integrates a Sigma 2D-powered graph rendering engine
with Graphology data models to provide rich, dynamic visualization
of relationships between code components, registries, contracts,
QA systems, and evidence surfaces.

**Tagline:** "Clarity in every connection."

**Architecture philosophy:** Governance, traceability, and safety
first. Every capability requires a contract before implementation.
Every accepted behavior requires Playwright evidence. Truth before
beauty — and then make it as beautiful as possible.

**Platform family:**
```
LumaWeave  → current product / graph engine
Lattica    → future broader platform family
Memory Palace → future spatial knowledge sidecar
```

**Vision horizon:** A near-living neuron labyrinth where developers
walk inside their architecture in VR, agents manifest as familiars,
and the graph breathes with audio reactivity. Clarity in every
connection, at every scale, in every dimension.

## 4. Key Systems

### QA / Advisory / Governance
- Active QA identity with advisory registry, proposals, backlog rows
- QA Bundle Validator (v70) prevents drift before Playwright cascades
- Contract-to-Code Trace Matrix links each contract to source/test/evidence
- Contract Trace Validator and System Index Validator running

### Graph Visual Inventory
- Fully traceable node/edge representation of contracts, registries
- Evidence surfaces with full QA linkage
- Read-only passive surfaces validated with Playwright
- Human/Evidence/Debug mode contract and registry accepted

### Audio / Signal Systems (Governance-Only)
- Synthetic signal preview and Music Reactive Mapping governed by contracts
- Audio Source Registry passive / read-only
- Universal audio handle routing: any handle in any layer can subscribe
- Motion Safety gate is master authority for all reactive effects
- Real audio: future, requires explicit promotion per source type

### Ghost Overlay / Grammar Lens (Partial)
- `data-lw-*` DOM attributes identify clickable elements
- Hold key + click → per-element config popout
- Live preview of changes in active rendering layer
- Cross-layer override cache: concept doc written, not yet implemented
- Global element type updates: not yet contracted

### Physics Dialects (Concept)
- Helix / DNA: brand layout, primary backbone + constellation branches
- Constellation: star-field spread, peaceful exploration mode
- Galaxy: orbital cluster model, hardest to implement, most spectacular
- All dialects bundle force layout + audio routing simultaneously

### Tile Workspace System (Concept)
- Movable, snappable, collapsible, fullscreen-capable tiles
- Right panel (physics) anchored by default, all others free
- Workspace configurations: named presets, saved per-lens
- Implementation: Phase 1 (fixed layout) → Phase 8 (full workspace)

## 5. Brand Identity

**Visual language:** The helix — the logo, the physics dialect,
the history slider, the brand mark signature line. All the same shape.

**Cluster colors (canonical):**
- Blue (#4fa3e0) — core/primary systems
- Purple (#a67de8) — governance/contracts
- Gold (#e0a84f) — active work/current
- Teal (#4fd9c8) — future/planned
- Green (#64d9a4) — accepted/stable
- Gray (#6a7485) — archive/logs

**Node shapes:** High-weight nodes = soft hexagon (from logo mark).
Default nodes = spheres. Cluster branch nodes = dots.

**Tile units:** Called "Tiles" — not widgets, panels, or modules.

**Navigation:** Six Lenses — Overview, Atlas, Evidence, Signal,
Workshop, Mission.

---

## 6. Forbidden Boundaries

- No Sigma/renderer mutation without explicit contract
- No audio input/playback/music reactivity without promotion
- No runtime command execution or storage persistence without contract
- No CSS variable writes without contract
- No Grammar Lens changes applied to inactive layer without
  cross-layer override cache contract
- No 3D rendering, VR, or Memory Palace without explicit contracts
- All evidence preserved and validated — no skipped tests
