# Normalized Source Graph Schema

All source adapters output the same normalized graph shape. This lets LumaWeave render websites, codebases, documents, APIs, databases, and other systems through one graph pipeline.

---

## Core TypeScript Types

```typescript
type LumaGraphNode = {
  id: string;
  label: string;
  type: string;           // e.g. "website.page", "code.file", "db.table"
  sourceAdapter: string;  // which adapter produced this node
  sourceUri?: string;
  sourcePath?: string;
  metadata: Record<string, unknown>;
};

type LumaGraphEdge = {
  id: string;
  source: string;         // node id
  target: string;         // node id
  type: string;           // e.g. "links_to", "imports", "foreign_key_to"
  label?: string;
  weight?: number;
  confidence: "observed" | "inferred" | "ai-inferred";
  evidence: SourceEvidence[];
  metadata: Record<string, unknown>;
};

type SourceEvidence = {
  kind: "file" | "url" | "line-range" | "selector" | "manifest" | "schema" | "model";
  uri?: string;
  path?: string;
  lineStart?: number;
  lineEnd?: number;
  selector?: string;
  excerpt?: string;
};

type LumaSourceGraph = {
  nodes: LumaGraphNode[];
  edges: LumaGraphEdge[];
  metadata: {
    adapterId: string;
    createdAt: string;
    inputSummary: string;
    extractionLayers: Array<"observed" | "inferred" | "ai-inferred">;
    warnings: string[];
    limitsHit: string[];
  };
};
```

## Confidence Types

### observed
Directly found in source. Example:
```
HTML link exists → links_to edge
Import statement exists → imports edge
Foreign key in schema → foreign_key_to edge
```

### inferred
Deterministic interpretation of observed source. Example:
```
Pages share topic keywords → possible relates_to edge
Files frequently changed together → inferred coupling edge
Sections share heading hierarchy → belongs_to edge
```

### ai-inferred
Generated by AI/semantic model. Must be visibly separable from observed:
```
Model suggests two concepts are related → ai-inferred relates_to
Model summarizes doc into themes → ai-inferred topic clusters
Model groups pages semantically → ai-inferred clusters
```

---

## Evidence Is Mandatory

Observed edges must have evidence. Examples:
```typescript
// URL evidence
{ kind: "url", uri: "https://example.com/docs", selector: "a[href='/api']", excerpt: "API Reference" }

// File line-range evidence
{ kind: "line-range", path: "src/App.tsx", lineStart: 12, lineEnd: 12,
  excerpt: "import { SettingsPanel } from './SettingsPanel';" }

// Schema evidence
{ kind: "schema", path: "db/schema.sql", excerpt: "FOREIGN KEY (user_id) REFERENCES users(id)" }
```

---

## Validation Rules

A normalized graph is valid when:
```
all node ids are unique
all edge ids are unique
all edge endpoints reference existing nodes
all observed edges have at least one evidence entry
confidence field is one of the three valid values
adapterId is present in metadata
node and edge counts are under configured limits
metadata.warnings and metadata.limitsHit are arrays (may be empty)
```

---

## Renderer Independence

The renderer should not need to know which adapter generated the graph. It relies only on:
```
node.type, node.label, node.metadata
edge.type, edge.confidence, edge.weight, edge.evidence
```

This enables graph filters:
```
show observed only
hide AI-inferred
show website.page nodes only
show high-confidence edges only
filter by sourceAdapter
```
