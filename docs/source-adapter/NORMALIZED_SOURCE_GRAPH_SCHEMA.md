# Normalized Source Graph Schema

## Summary

All source adapters should output the same normalized graph shape. This lets LumaWeave render websites, codebases, documents, APIs, databases, and other systems through one graph pipeline.

## Core Types

```ts
type LumaGraphNode = {
  id: string;
  label: string;
  type: string;
  sourceAdapter: string;
  sourceUri?: string;
  sourcePath?: string;
  metadata: Record<string, unknown>;
};

type LumaGraphEdge = {
  id: string;
  source: string;
  target: string;
  type: string;
  label?: string;
  weight?: number;
  confidence: "observed" | "inferred" | "ai-inferred";
  evidence: SourceEvidence[];
  metadata: Record<string, unknown>;
};

type SourceEvidence = {
  kind: "file" | "url" | "line-range" | "selector" | "manifest" | "schema" | "model";
  uri?: string;
  path?: string;
  lineStart?: number;
  lineEnd?: number;
  selector?: string;
  excerpt?: string;
};

type LumaSourceGraph = {
  nodes: LumaGraphNode[];
  edges: LumaGraphEdge[];
  metadata: {
    adapterId: string;
    createdAt: string;
    inputSummary: string;
    extractionLayers: Array<"observed" | "inferred" | "ai-inferred">;
    warnings: string[];
    limitsHit: string[];
  };
};
```

## Node Requirements

Every node should have:

```txt
stable id
human-readable label
type
sourceAdapter
sourceUri or sourcePath when available
metadata
```

Examples:

```txt
website.page
website.heading
code.file
code.symbol
api.endpoint
db.table
infra.service
markdown.note
```

## Edge Requirements

Every edge should have:

```txt
stable id
source node id
target node id
type
confidence
evidence
metadata
```

Examples:

```txt
links_to
imports
calls
has_heading
mentions_topic
uses_schema
foreign_key_to
depends_on
blocks
cites
```

## Evidence Is Mandatory

Edges should not appear without evidence unless explicitly marked as experimental or AI-inferred.

Examples:

```ts
{
  kind: "url",
  uri: "https://example.com/docs",
  selector: "a[href='/api']",
  excerpt: "API Reference"
}
```

```ts
{
  kind: "line-range",
  path: "src/App.tsx",
  lineStart: 12,
  lineEnd: 12,
  excerpt: "import { SettingsPanel } from './SettingsPanel';"
}
```

## Confidence Types

### observed

Directly found in source.

```txt
HTML link exists.
Import statement exists.
Foreign key exists.
OpenAPI endpoint references schema.
```

### inferred

Deterministic interpretation of observed source.

```txt
Pages share topic keywords.
Files frequently changed together.
Sections belong to same heading hierarchy.
```

### ai-inferred

Generated by AI/semantic model.

```txt
A model suggests two concepts are related.
A model summarizes a document into themes.
A model groups pages into semantic clusters.
```

AI-inferred relationships must remain visibly separable from observed relationships.

## Graph Metadata

Each graph should include ingestion metadata:

```txt
adapter used
input source
limits applied
warnings
skipped files/pages
errors
node/edge counts
observed/inferred/AI edge counts
```

This metadata should feed Mission Control’s ingestion QA report.

## Validation Rules

A normalized graph is valid if:

```txt
all node ids are unique
all edge ids are unique
all edge endpoints exist
all observed edges have evidence
confidence is valid
adapter id is present
node and edge counts are under configured limits
metadata includes warnings/errors arrays
```

## Future Renderer Use

The renderer should not need to know which adapter generated the graph. It should rely on:

```txt
node.type
edge.type
confidence
weight
metadata
```

This enables graph filters like:

```txt
show observed only
hide AI-inferred
show website pages only
show API endpoints only
show high-confidence edges
```
