# Theme Customization Scaffolding Plan

## Purpose

Prepare for a future full theme customization menu without building it prematurely.

## Current-Phase Safe Work

Allowed now:
- define graph visual tokens
- centralize color/font-size values
- make active controls honest
- mark non-wired controls Planned
- document future color picker architecture

Not allowed yet:
- full pop-out color picker
- HSV/alpha/swatch editor
- full app-wide theme token migration
- Solar Plasma final visuals
- import/export theme system

## Future Theme Menu Sections

- Node colors
- Edge colors
- Node labels
- Edge labels
- Hover/selection
- Panels
- Background/starfield
- Presets
- Import/export
